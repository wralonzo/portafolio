Sobre mí

Me llamo Willian Roberto Alonzo Pérez. Soy Desarrollador de Software Full Stack apasionado con más de 3 años de experiencia en el diseño, desarrollo e implementación de aplicaciones móviles, web y arquitecturas backend para sectores clave como Banca, Logística y Gestión Empresarial en Guatemala.

En el área de Desarrollo Mobile & Multiplataforma, cuento con experiencia comprobada en Flutter (Dart), React Native, Ionic, Jetpack Compose (Kotlin/KMP) y geofencing para automatización de control operativo en campo.

Como Ingeniero Backend & Cloud, me especializo en construir APIs escalables y seguras con Node.js (NestJS, Express), Java Spring Boot (JPA), Rust, Python (Django, Flask) y PHP (CodeIgniter), integrando biometría facial (FacePhi), OCR, bases de datos (PostgreSQL, Oracle PL/SQL, MySQL, MongoDB) y contenedores Docker en AWS.

Mi enfoque está orientado a resultados, trabajo colaborativo en metodologías ágiles (Scrum), rigor técnico y aplicación de principios SOLID para entregar software sostenible alineado a los objetivos del negocio.
